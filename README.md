# Viks

A modern React application built with Vite and Material-UI.

## 🚀 Live Demo

[https://unoriginalNameCS.github.io/Viks](https://unoriginalNameCS.github.io/Viks)

## 🛠️ Tech Stack

- **React** - UI library
- **Vite** - Build tool
- **Material-UI** - Component library
- **React Router** - Navigation
- **ESLint** - Code linting

## 📦 Installation

```bash
cd frontend
npm install
```

## 💻 Development

```bash
npm run dev
```

The app will run at `http://localhost:5173`

## 🏗️ Build

```bash
npm run build
```

## 🚢 Deployment

### Manual Deployment

```bash
npm run deploy
```

### Automatic Deployment

Changes pushed to the `main` branch automatically deploy via GitHub Actions.

## 📝 Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run ESLint
- `npm run preview` - Preview production build
- `npm run deploy` - Deploy to GitHub Pages
